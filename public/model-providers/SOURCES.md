# Model author identity assets

Fetched on 2026-09-03 and stored locally so the catalog has no runtime dependency on third-party image hosts.

- Each GitHub asset is the current profile image published by the account named in `src/lib/catalog/official-marks.ts`.
- Inception's icon comes directly from `https://www.inceptionlabs.ai/`.
- These assets identify model authors. They do not imply endorsement, partnership, or ownership by Nexus.
- All marks and profile images remain the property of their respective owners.
- Nexus does not claim that every individual model has a distinct official cover image; the verified author identity is used when the author has not published one.

The canonical source URL for every file is kept next to its mapping in `src/lib/catalog/official-marks.ts`.
